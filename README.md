## Installation

Clone the repository:

```bash
git clone https://github.com/raheesnelliyali-in/personal-portfolio.git
```

Go to project folder:

```bash
cd personal-portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
