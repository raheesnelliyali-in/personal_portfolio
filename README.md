# Muhammed Rahees N - Portfolio

A professional personal portfolio built with React, Vite, and Tailwind CSS.

## Sections Included

- Hero profile section
- About me
- Skills grouped by category
- Internship experience
- Project showcase
- GitHub contribution heatmap
- Education
- Learning timeline
- Certificates / learning proof
- Achievements
- Resume CTA
- Contact links

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React Icons

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

- Replace `public/profile-photo.jpg` with your photo.
- Add your resume as `public/resume.pdf`.
- Update project links inside `src/sections/Projects.jsx`.
